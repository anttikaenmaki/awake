# Homebrew tap for Awake

[Awake](https://github.com/anttikaenmaki/awake) keeps a Mac awake, also with the lid closed, from the menu bar or Terminal.

```bash
brew install anttikaenmaki/awake/awake
```

Homebrew downloads the release and runs Awake's own installer, which builds the app on your Mac. `brew upgrade` updates Awake in place and keeps its settings; `brew uninstall awake` removes it. See [Awake's README](https://github.com/anttikaenmaki/awake#readme) for everything else.

This repository is written by the release workflow of the awake repository, from `tools/homebrew/` there. Change the files there, not here.
